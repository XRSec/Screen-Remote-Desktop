## 当前 UI 范围

1. **应用列表**：搜索、最近使用、收藏、全部应用网格、应用名称和状态。
2. **消息通知**：通知来源、时间、摘要、关闭、固定和快捷回复。
3. **消息卡片**：头像、发送者、正文、图片附件和操作按钮。
4. **照片**：缩略图网格、加载状态、预览及导出操作。
5. **信息**：会话列表、未读状态、聊天详情、输入框和附件入口。

明确不包含：电话、配对页面、iOS 宣传图、Windows 开始菜单集成和厂商品牌宣传图。

其中 `09-xda-app-list-and-notifications.jpg` 同时覆盖当前最重要的“应用列表 + 通知卡片”，建议作为整体信息架构的主参考；微软官方图片继续用于核对具体模块和更高分辨率细节。
